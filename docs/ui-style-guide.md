# survivor-demo UI 风格小规范（第一轮）

> 目标：先让 HUD / 提示 / 按钮可读、可懂、可操作，再把当前 demo 往“西游记古风 Q 版”方向统一一层。

## 本轮已落地的方向

### 1. 文案语气
- 核心原则：**信息先清楚，再上氛围。**
- 保留清晰的数值与操作说明，但把英文原型词替换为更统一的中文表达。
- 示例：
  - `Wave` → `第X劫`
  - `Stage` → `妖势阶段名`
  - `Kills` → `斩妖`
  - `Enemies` → `妖群`
  - `XP` → `修为`
  - `Weapon` → `法术`
  - `Dash` → `筋斗闪`

### 2. 阶段命名
- 劫波名：`花果山热身 / 山门妖风 / 流沙急袭 / 白骨夜行 / 火云压阵 / 金箍镇场`
- 难度阶段：`初入山门 / 妖气渐浓 / 群怪躁动 / 魔障翻涌 / 压迫成潮 / 大圣护场`
- 命名目标：让玩家感到是“轻西游、Q 版、带试炼氛围”，但不影响即时理解。

### 3. 视觉语言
- 主色：暖金、朱砂、墨褐。
- 辅色：修为绿、提示青、危险红。
- HUD 面板改成深底描金思路，按钮统一成暖色块 + 金边。
- 弹字与触控摇杆同步换成同一套暖金/朱砂/墨色体系。
- 信息布局分三层：
  - 左上主 HUD：长期数值（命火、斩妖、法术、目标）
  - 顶部横幅：阶段切换、升级、关键战斗播报
  - 右上状态卡：只放“此刻最该知道的一句话”，比如回命进度、低血量预警、终局压阵提醒

### 4. 可用性补充
- 浏览器失焦提示与局内失败/通关提示复用同一块中央信息面板，保证玩家不会错过“为什么现在不能动 / 下一步怎么做”。
- 移动端提示不只是静态教学，低血量与终局时允许切成更短促的行动建议，优先服务存活。
- 战斗弹字允许轻微放大后淡出，增强命中、回血、升级时的读感。

### 5. 面板与演出第二轮
- 暂停 / 失败 / 通关统一收口为“戏台战报”体系：有题头、有评语、有本局关键数据，不再只是单句提示。
- 新增常驻暂停按钮，并支持 `Esc / P` 快速暂停，方便网页试玩和录屏验收时随时截面。
- 右上状态卡会随命火告急、终局压阵、暂停、通关等状态切换底色与强调色，让“现在最重要的信息”更显眼。

### 6. 角色 / 敌人统一感第二轮
- 玩家与三类敌人先从纯几何块，提升到“Q 版纸片戏 / 木偶戏”方向：加入影子、脸谱、披风 / 面甲 / 冠饰 / 护甲等简单部件。
- 优先统一剪影与配色关系：主角偏暖金 + 朱砂，敌人偏褐红 / 橙褐 / 甲胄金，减少原型阶段那种互相不搭的随机色块感。

### 7. HUD / 战报第三轮收口
- 主 HUD 继续保持“左上主账本、顶部播报、右上状态签”的三层结构，但要进一步做出层次分区：
  - 左上主 HUD 用细分隔条把“基础数值 / 波次信息 / 目标与提示”拆开，减少信息糊在一块的原型感。
  - 顶部横幅改成“标题 + 副标题”的戏台播报样式，关键节点除了主句，还要给玩家一个类别感（如妖潮播报、修为播报、战报播报）。
  - 右上状态卡不只显示一句话，还要保留一个短徽签（香火签 / 告急签 / 军令签等），让它像一张即时战况签条。
- 结果页按钮要拉开主次：`再闯一局` 作为主动作，用高饱和朱砂金边；`继续试炼` / `暂停` 用更克制的深墨金边，避免结果页和局内按钮全部同权重。

### 8. 角色 / 敌人统一感第三轮
- 主角继续补“眉眼、肩甲、下摆”等极少量纸片戏细部，让第一眼从“能看懂”提升到“有角色味”。
- 基础怪、快怪、重装怪都要至少有一处能远看识别的戏曲部件：眉眼 / 头焰 / 牙饰 / 肩甲 / 腰甲等，保证同属一个西游 Q 版世界观，而不是三套互不相干的几何色块。
- 所有新增细节依然遵守低成本原则：只用简单 Polygon 叠片，不引入重资源依赖，不牺牲当前可读性和 Web 体量。

## 后续延展建议

### 优先级 P1
- 把角色、敌人、弹丸也逐步从几何原型色块统一到“Q 版纸片戏 / 木偶戏”感。
- 给精英怪增加更明确的边框、冠饰、尾焰或标记。

### 优先级 P2
- 接入正式字体资源（当前仍使用引擎默认字体，风格只靠配色与文案先撑住）。
- 在现有战报面板基础上继续增加更明显的卷轴感、边框纹样与正式字体资源。

## 本轮不做的事
- 不新增复杂结算系统。
- 不重做大规模场景美术。
- 不为了风格化牺牲当前可用性与可读性。
