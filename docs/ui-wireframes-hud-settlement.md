>
> 本文只定义 **信息层级 / 页面骨架 / 组件清单 / 响应式重排建议**，不改玩法逻辑。

## 1. 设计总原则

### 1.1 信息优先级
1. **活着最重要**：命火、当前危险态、当前目标
2. **战斗节奏第二**：波次 / 劫波 / 妖潮阶段 / 关键播报
3. **成长反馈第三**：修为、斩妖、连斩、升级提醒
4. **操作入口第四**：暂停 / 继续 / 再闯一局

### 1.2 视觉语法
- **长期常驻信息**：深底描金，偏“账本 / 战报牌”
- **短时战斗播报**：朱砂强调，偏“戏台横幅 / 军令条”
- **紧急状态**：高对比朱红，不靠长句解释
- **总结页数据**：卷轴分栏 + 印章收尾，强调“可截图传播”

### 1.3 骨架原则
- HUD 采用 **左上主账本 + 顶部播报条 + 右上状态签 + 底部操作带** 四区结构
- 结算页采用 **题头 + 战报主体 + 印章评语 + CTA 带** 四段结构
- 桌面与手机竖屏共用同一套组件语义，只调整排布

### 桌面横屏 HUD 说明
- **左上主账本**：本局最稳定、最常看的数据区。
- **顶部播报条**：只处理短时关键事件，不与主账本抢长期注意力。
- **右上状态签**：永远只说“当下最该做什么”。
- **底部操作带**：弱化存在，但要稳定承接暂停、重开、法术/操作提示。

### 桌面横屏 HUD 组件清单
1. `hud_main_panel`
   - 命火
   - 修为
   - 斩妖
   - 连斩（可选保留）
   - 第几劫 / 波次
   - 当前目标一句话
2. `hud_broadcast_banner`
   - 主标题
   - 副签 / 类别签（妖潮 / 修为 / 战报）
3. `hud_status_tag`
   - 小徽签
   - 正文一句话
4. `hud_action_tray`
   - 暂停提示
   - 当前法术 / 局内辅助说明

```text
│  └──────────────────────────────────────┘       │
└──────────────────────────────────────────────────┘
```

### 手机竖屏 HUD 说明
- **主账本压缩但不折叠**：命火、修为、斩妖、第几劫仍要一眼可见。
- **状态签抬到右上**：避免压住左下摇杆与底部操作带。
- **操作带缩窄**：不覆盖摇杆和闪避按钮活动区。
- **播报条仍在顶部中央**：保持与桌面版同语义骨架。

### 手机竖屏重排规则
- 当宽度不足时：
  - 连斩可降级为非默认展示
  - 当前目标保留一句话，不换两行说明书
  - 状态签正文限制 8~12 字
- 不能发生：
  - 播报条与状态签重叠
  - 操作带压住摇杆
  - 主账本过高导致战斗可视区塌陷

## 3. 结算页低保真线框

## 3.1 结算共骨架（胜 / 败 / 暂停）

```text
┌──────────────────────── 结算页 / 战报页 ────────────────────────┐
│                                                                  │
│                   [ 题头牌匾 / 戏台战报标题 ]                     │
│                 今日凯旋 / 此劫未竟 / 暂歇戏台                    │
│                                                                  │
│        ┌──────────────── 战报主体卷轴 / 账页 ────────────────┐    │
│        │ 时长        03:12        斩妖        168            │    │
│        │ 最长连斩    24           劫波        第6劫          │    │
│        │ 命火结余    02/10        法术        金箍火花        │    │
│        │                                                  │    │
│        │ 战绩评语：火云压阵之下，尚能稳住阵脚。             │    │
│        │ [印章位：凯 / 败 / 歇]                              │    │
│        └──────────────────────────────────────────────────┘    │
│                                                                  │
│            [次 CTA] 继续试炼      [主 CTA] 再闯一局             │
│                     [辅助 CTA] 返回主菜单                       │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### 结算页区块说明
- **题头牌匾**：用一句话定性本局结果。
- **战报主体卷轴**：核心数据统一排版，避免碎片式卡片化。
- **战绩评语**：只写一条，增强戏台战报感。
- **印章位**：给截图一个“结尾钉子”。
- **CTA 带**：主次明确，右侧主按钮固定为 `再闯一局`。

---

## 3.2 胜 / 败 / 暂停三态差异

### 胜利态：`今日凯旋`
- 题头偏暖金 + 朱砂
- 印章偏“凯”或“胜”
- 评语更鼓劲：
  - `妖潮已散，可再上一场。`
  - `护场有功，今日得势。`

### 失败态：`此劫未竟`
- 题头偏墨褐 + 暗朱
- 印章偏“败”或“整备”
- 评语强调再战，不用挫败腔：
  - `阵脚已乱，且再整行装。`
  - `妖势太盛，换一轮打法更稳。`

### 暂停态：`暂歇戏台`
- 题头偏中性金褐
- 印章偏“歇”
- 评语更功能化：
  - `戏台暂歇，整顿后再上。`
