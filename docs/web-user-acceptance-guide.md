# Web 试玩验收说明（给最终试玩用户）

> 这份说明是给**最终试玩 / 验收用户**看的。
>
> 只讲怎么打开、卡住时怎么判断、什么时候等、什么时候刷新、什么时候反馈。
>
> 如果你是项目维护人或需要排查技术问题，请看工程手册，不要把那一套发给试玩用户。

## 适用场景
- 手机上打开 survivor-demo 网页试玩
- 临时验收链接第一次发给体验者时
- 需要用最少步骤判断“继续等 / 刷新 / 反馈问题”时

## 一句话版本
1. 点开链接
2. 第一次打开会比较慢，先等一会儿
3. 如果加载提示还在变化，继续等
4. 如果长时间停住不动，刷新一次
5. 刷新后还不行，再截图反馈

## 怎么打开
### 手机端（优先）
- 直接点开试玩链接
- 建议用：
  - 手机系统浏览器
  - Chrome
- 打开后请先停留在页面里，不要马上切后台

### 电脑端
- 直接在浏览器里打开试玩链接即可
- 建议用 Chrome 或 Edge

## 第一次打开慢，是正常还是异常？
### 正常情况
第一次打开网页游戏时，通常会先下载游戏运行需要的内容，所以**第一次会比后面慢**。

如果你看到页面上有加载提示，而且提示内容或进度还在变化，通常说明**还在正常加载**，可以继续等。

### 可以先继续等的情况
出现下面任一情况，可以先等：
- 页面上有“加载中”提示
- 提示文字在变化
- 进度条在前进
- 页面显示“第 1 / 2 / 3 步”之类的加载阶段

### 该认为“不太正常”的情况
出现下面情况，就不要一直傻等：
- 页面一片空白，长时间没有任何提示
- 同一条加载提示停了很久都没变化
- 过了较长时间还是没进游戏

## 看到什么提示时，该等 / 刷新 / 反馈？

### 情况 A：有加载提示，而且提示还在变化
**怎么做：继续等。**

例如你看到：
- 正在加载
- 正在进入游戏
- 第 1 / 2 / 3 步加载中
- 进度条还在动

这通常说明页面没有卡死，只是第一次打开比较慢。

---

### 情况 B：有加载提示，但同一行提示停住很久不动
**怎么做：先刷新一次。**

你可以理解成：
- 还在同一个加载步骤
- 但等了比较久都没变化

这时候先做一次：
- 下拉刷新，或
- 点击浏览器刷新

如果刷新后能进，就是临时卡住，不用额外处理。

---

### 情况 C：页面空白 / 黑屏 / 只有底色，没有明显提示
**怎么做：不要一直等，直接刷新一次。**

如果刷新后还是一样，再反馈问题。

---

### 情况 D：刷新一次后还是进不去
**怎么做：反馈。**

反馈时请尽量一起发这 4 样：
1. 截图一张
2. 你看到的是空白、卡住，还是停在某一步
3. 手机型号 / 浏览器名称
4. 你用的是 Wi‑Fi 还是手机流量

这样我们能更快判断问题，不会来回追问很多轮。

## 推荐的最少操作
### 第一次打开
- 点开链接后，先等一会儿
- 只要提示还在变化，就先不要反复刷新

### 如果感觉卡住了
按这个顺序来：
1. 刷新一次
2. 还不行的话，换一个浏览器再试一次
3. 还不行，再截图反馈

## 不建议的做法
- 不要连续刷新很多次
- 不要一边加载一边频繁切后台
- 不要只发一句“打不开了”

比起“打不开了”，更有用的反馈是：
- “一直停在加载页面”
- “刷新后还是白屏”
- “手机浏览器打开后停在第 2 步”

```text
打开链接后先等一会儿，第一次通常最慢。
如果页面上的加载提示还在变化，就继续等。

```
